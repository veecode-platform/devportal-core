# DevPortal 3.0.0 release notes

## Product face overrides

DevPortal 3.0.0 pins its built-in product-face plugins to OCI artifacts by digest. An override that names a face plugin by its former `./dynamic-plugins/dist/...` path no longer matches it. The OCI face default remains enabled. Set `package` under `global.dynamic.plugins` to the full OCI reference in the [product face override guide](https://github.com/veecode-platform/devportal-chart/blob/main/docs/product-face-overrides.md).
