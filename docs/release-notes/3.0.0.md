# DevPortal 3.0.0 release notes

## Product face overrides

DevPortal 3.0.0 pins all 20 product-face entries to OCI artifacts by digest. Eighteen are enabled by default; the stock Home page and legacy theme are disabled.

An override keyed by a former `./dynamic-plugins/dist/...` path no longer matches the moved face entry, so its default remains enabled. Use the current full OCI reference in `global.dynamic.plugins` to disable or reconfigure a face plugin.

A tag or digest in an override pins that artifact version. Update or remove the override when the face changes. See the [product face override guide](https://github.com/veecode-platform/devportal-chart/blob/main/docs/product-face-overrides.md).
